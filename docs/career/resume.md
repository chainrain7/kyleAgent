## 2. 三分钟讲项目骨架

1. **一句话定位**(10s):"值班工程师半夜收到告警,我的系统自动查日志查指标定位根因,
   给出处置建议,危险操作必须他点批准才执行,完事自动出带证据链的报告。"
2. **为什么不是套壳**(30s):daemon+多客户端运行时、类型化 JSON-RPC 协议文档同源生成、
   事件流/trace 三层可观测——重点讲"审批为什么是一等公民"。
3. **评测方法论**(60s,最大差异点):三重断言的设计动机——回答对不对(关键词)、
   动手对不对(多重集合相等)、该不该动手(诊断类零变更);预授即审批的两层安全证据;
   首轮 80% 的失败怎么用 cassette 归因(排查瘫痪→runbook 补效率原则)。
4. **两个深挖模块**(60s):变更恢复语义(动作↔故障类型精确匹配、传导自动解除、
   表象与根因分离的 S7/S8);纯文件模拟环境的决策链(确定性/CI/可断言)。
5. **收尾**(20s):回放 2.5 秒 20/20、449 测试、三平台 CI——工程收口。

## 3. 高频追问与答点

**Q: 为什么自己写运行时不用 LangChain/LangGraph?**
审批挂起(Future)、事件流外化、cassette 评测、durable 快照都要在循环层做一等公民;
框架把这些埋在回调里,改造成本高于自研,且教学/简历价值在引擎不在胶水。

**Q: 怎么证明 Agent 没有乱执行危险命令?**
两层:评测层变更调用集合与期望逐项相等(多/少都红);审批层不预授走真实 ASK
的集成测试(拒绝后状态不动)。零越权是断言出来的,不是"看起来没有"。

**Q: LLM 输出不稳定怎么办?**
cassette 录制/回放:顺序匹配(工具输出含时间戳,内容哈希必 miss);回放时工具在
隔离环境真实重执行,LLM 响应来自录制——CI 里 2.5 秒确定性回归 20 剧本。

**Q: 80% 到 100% 改了什么?会不会是过拟合?**
只改了知识库(runbook 效率原则)、goal 措辞、一个剧本的步数预算;断言一行没动。
改 runbook 影响的是所有用到该手册的剧本的先验知识——这是产品迭代不是过拟合;
且有回放门禁防止回归。

**Q: 模拟环境会不会太玩具?**
工程决策:纯文件换三件事——回放确定性(工具重执行结果一致)、Windows CI 可跑、
终态即文件可直接断言;对外只留 adapter 接口。演示价值在方法论不在环境仿真度。

**Q: 为什么 DeepSeek 不是 Claude?**
协议边界设计:消息格式以 Anthropic 形态为规范,兼容端点(Anthropic/OpenAI 双
provider)在边界内做翻译,核心循环零感知——换模型是配置不是改造。

## 4. 五分钟演示脚本

> 环境:`uv sync --extra webui` 已装;两个终端;浏览器开 http://127.0.0.1:8080

0. **开场**(30s):README 截图页——"这是值班工作台:左边告警队列和服务健康,
   右边诊断对话,每个危险操作都有审批卡。"
1. **注入故障**(30s):点"故障演练"→ 选 `orders-config-typo-errors` →
   告警卡出现、orders 变黄、err 8% 高亮。
2. **发起诊断**(30s):点告警卡 → 输入框自动填好标准处置指令 → Enter。
3. **观察诊断**(60s):Agent 并行查告警/状态/日志 → 工具行依次变绿 →
   给出根因(发布引入坏配置)。
4. **审批时刻**(60s,高潮):变更审批卡弹出,带影响面
   ("依赖方 gateway 健康检查将瞬时失败约 30s")→ 讲"这里人是一票否决权" → 按 y。
5. **恢复与报告**(60s):restart 执行、告警转 RESOLVED、服务回绿、
   侧栏出现报告 → 点开:结论/处置(含审批决策)/时间线/证据链。
6. **收口评测**(60s):`uv run python scripts/run_evals.py --suite oncall --replay`
   → 20/20, 2.5 秒 → "这个闭环在 CI 里每次提交都跑,谁改坏了值班行为直接红。"
