交互要点:

- **告警卡片点击** → 输入框自动填入该告警的标准诊断指令并聚焦(用户按 Enter 发起);【P0】
- **服务健康卡**:`●` running 绿 / `▲` degraded 黄 / `✕` down 红 + 副本数与 err%,3s 轮询;【P1】
- **演练下拉**:列 20 剧本(id + 现象一句话),点击注入;`↺重置` 恢复基线环境;【P1】
- 工具行/权限卡/流式 Markdown 交互沿用现有实现。
