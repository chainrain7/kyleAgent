三、缺陷清单

P0 · 阻断  三处 encoding= 参数误加，导致运行时 TypeError

共同特征：这是一次「给文本读写补 utf-8」的批量改动，其中 read_text(encoding=...) / write_text(encoding=...) 的修改是正确的，但同一批改动把该参数误加到了 str.join()、str()、json.dumps() 上。仓库 HEAD 中这三处均为正确写法。

src/kyle_agent/oncall/sim.py:124
- log_path.write_text("\n".join(lines) + "\n", encoding="utf-8")
+ log_path.write_text("\n".join(lines, encoding="utf-8") + "\n", encoding="utf-8")
  TypeError: str.join() takes no keyword arguments
  触发条件：baseline/logs/*.log 存在时，SimEnv.reset → _materialize_timestamps 必崩。
  影响面：50 项单测失败（oncall 全族 + task_manager 1 项）。

src/kyle_agent/cli/commands/core.py:88
- _PID_FILE.write_text(str(proc.pid))
+ _PID_FILE.write_text(str(proc.pid, encoding="utf-8"))
  TypeError: str() 不接受 encoding 关键字（且 proc.pid 为 int 而非 bytes）。
  影响面：kyle core start 写 pid 文件时崩溃，daemon 启动链路受损。

src/kyle_agent/core/task/manager.py:115
- f.write_text(json.dumps(data, indent=2, ensure_ascii=False))
+ f.write_text(json.dumps(data, indent=2, ensure_ascii=False, encoding="utf-8"))
  TypeError: json.dumps() 无 encoding 参数。
  影响面：_clear_dependency 路径，test_update_completed_clears_dependency 失败。

确定性复现（不依赖覆盖率环境）：构造含 app.log 的临时环境目录并调用 SimEnv._materialize_timestamps()，原生解释器稳定抛出 TypeError: str.join() takes no keyword arguments；单独运行 tests/unit/test_oncall_bridge_api.py 为 2 failed / 1 passed。
